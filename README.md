# Valk

A simple Black Desert Online Discord bot for tracking a guild roster & member gear

## Installation

```bash
# Install dependencies
npm i
# Build the application
npm run build
# Run the built server with node.js
# Note: build is the default output folder, move it elsewhere such as /opt for production
node build
```

## Development

```bash
# Install dependencies
npm i
# Run the application in development mode
npm run dev
```
